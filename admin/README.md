# AAURIKAA Admin

Mobile-first ecommerce admin console. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_API_BASE_URL`.

```bash
npm install
npm run dev
```

Open [http://localhost:3001/admin/login](http://localhost:3001/admin/login) and sign in with a real Admin account from the backend. Do not store admin passwords in this repository.
